# Vridhi Engineering OS — V5

Private-first personal engineering manager for a Java backend + DSA track.

## Included
- 365-day Java backend + DSA roadmap
- Daily learning, DSA, project work and evidence connected
- Reopen/edit any day
- Forward unfinished manager tasks with history
- 8 staged portfolio projects
- Exact official resources at day/project level
- Evidence-first LinkedIn workflow + calendar export
- Local-first Jarvis with no external AI calls, shell access, browser control or credentials
- Analytics, backup/import and reset
- Responsive frontend for desktop and mobile
- Loading and runtime error states

## Safety
Never put passwords, API keys, SSH keys, cookies, recovery codes or private tokens into the app. Profile URLs are only links; they do not grant account access.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm start
```

## Deploy
Import the repository into Vercel. No environment variables are required for this local-first version.
